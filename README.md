# Bincom Python Assessment

## Project Description
This project was developed as part of the Bincom Python Trainee technical assessment.

It extracts shirt colours from an HTML file, analyses their frequencies and performs additional Python programming tasks.

## Features
- Extracts colours from an HTML table using BeautifulSoup.
- Counts the frequency of each colour.
- Calculates mean, median, mode and variance using alphabetical numerical encoding.
- Calculates the probability of selecting RED.
- Saves colour frequencies into a PostgreSQL database.
- Implements a recursive search algorithm.
- Generates a random 4-digit binary number and converts it to decimal.
- Calculates the sum of the first 50 Fibonacci numbers.

## Technologies Used
- Python
- BeautifulSoup
- PostgreSQL
- psycopg2

## How to Run
1. Install the required packages:
   `pip install beautifulsoup4 psycopg2-binary`
2. Ensure PostgreSQL is running and the database is configured.
3. Place `python_class_question.html` in the same folder as the Python script.
4. Run:
   `python bincom_binary.py`
